Project Description

This project analyses YouTube political discussions related to the Tamil Nadu Election 2026 using Natural Language Processing (NLP), sentiment analysis, temporal analytics, topic modelling, correlation analysis, and Social Network Analysis (SNA).

The project investigates:
- political discussion trends
- public sentiment patterns
- election-related temporal activity
- topic modelling and discussion themes
- political interaction networks
- online visibility versus election outcomes
